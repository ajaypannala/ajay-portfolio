# Ajay Kumar Pannala — Portfolio

A responsive personal portfolio website for a Java Full Stack Developer fresher.

## Built with
- HTML5
- CSS3
- Vanilla JavaScript

## Sections
- Introduction and availability
- About and education
- Technical skills
- Selected project work
- Internship and education journey
- Contact links

## Run locally
Open `index.html` in a browser. No build step or package installation is required.

## Deploy on Vercel
Import this GitHub repository in Vercel. The site is static; use the repository root as the root directory and leave the build command and output directory empty/default. Vercel can serve `index.html` directly.
